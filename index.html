Connect Microsoft 365

One-time setup so that Email in Outlook and Remind in Teams can put the picture inside the draft or message by themselves (no Ctrl+V). The tracker talks to your own Microsoft 365 account, and nothing is sent to anyone else.

  1. Open entra.microsoft.com → App registrations → New registration. Name it “IT Follow-up Tracker”, choose this organisation only.
  2. Under Redirect URI choose Single-page application (SPA) and enter
  3. Open API permissions → Add → Microsoft Graph → Delegated and add: User.Read, Mail.ReadWrite, Chat.Create, Chat.ReadWrite, ChatMessage.Send. (Click “Grant admin consent” only if your tenant asks for it.)
  4. Copy the Application (client) ID and Directory (tenant) ID from the Overview page into the boxes below.
